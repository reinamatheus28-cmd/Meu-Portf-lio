# Portfólio — Matheus Reina

Portfólio pessoal responsivo feito com HTML, CSS e JavaScript puro.

## Arquivos

- `index.html` — estrutura e conteúdo das seções.
- `style.css` — cores, layout, responsividade e animações.
- `script.js` — menu mobile, animações de entrada e destaque da navegação.
- `foto.jpg` — adicione aqui sua foto pessoal (não incluída ainda).

## Como abrir no VS Code

1. Extraia o arquivo ZIP para uma pasta.
2. Abra o VS Code e escolha **Arquivo > Abrir Pasta**.
3. Para ver o site, abra `index.html` no navegador. Recomendado: instale a extensão **Live Server**, clique com o botão direito em `index.html` e selecione **Open with Live Server**.
4. Coloque sua foto na pasta do projeto com o nome `foto.jpg`.
5. Edite `index.html` para atualizar sua apresentação, links do GitHub, e-mail e projetos. Procure por `PERSONALIZE O LINK` e `seuemail@exemplo.com`.

## Como publicar no GitHub Pages

1. Entre em https://github.com/ e crie um repositório público, por exemplo `meu-portfolio`.
2. Envie os arquivos `index.html`, `style.css`, `script.js`, `README.md` e sua `foto.jpg` para a raiz do repositório.
3. No repositório, abra **Settings > Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde a publicação. O GitHub mostrará o endereço do site na própria página de Pages.

## Antes de publicar

- Troque o e-mail de exemplo pelo seu.
- Atualize os links dos projetos com os repositórios reais.
- Confira se todas as tecnologias listadas correspondem ao que você já estudou ou está estudando.
- Não envie dados pessoais que não queira deixar públicos.
